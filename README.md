# Manajemen Tugas & Biaya Kuliah

Aplikasi web untuk membantu mahasiswa mengelola tugas kuliah dan mencatat pengeluaran biaya kuliah secara lebih terstruktur.

## Tentang Project

Project ini dibuat sebagai personal project untuk membantu mahasiswa dalam:

- Mengelola daftar tugas kuliah.
- Memantau status pengerjaan tugas.
- Mencatat pengeluaran biaya kuliah.
- Melihat total pengeluaran berdasarkan semester.
- Memantau ringkasan tugas dan keuangan melalui dashboard.

## Fitur Utama

### Manajemen Tugas

- Menambahkan tugas kuliah.
- Mengedit dan menghapus tugas.
- Mengatur status tugas:
  - Belum Dikerjakan
  - Sedang Dikerjakan
  - Selesai
- Memindahkan tugas menggunakan sistem Kanban drag-and-drop.
- Menyimpan informasi mata kuliah, dosen, deadline, dan deskripsi tugas.

### Manajemen Biaya Kuliah

- Menambahkan catatan pengeluaran.
- Mengelompokkan pengeluaran berdasarkan kategori.
- Mengatur pengeluaran berdasarkan semester.
- Mengedit dan menghapus data pengeluaran.
- Menghitung total pengeluaran secara otomatis.
- Menampilkan grafik pengeluaran per kategori dan semester.
- Mengekspor laporan pengeluaran ke dalam format PDF.

### Autentikasi Pengguna

- Registrasi akun.
- Login pengguna.
- Logout.
- Fitur lupa password dan reset password.
- Data tugas dan pengeluaran tersimpan berdasarkan akun pengguna.
